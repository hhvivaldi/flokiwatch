TESTED

Optimization Roadmap

7 features rigorously tested via data analysis on 662 backtest trades (Aug 2024 → Feb 2026, 18 months). All seven confirmed the system is already well-optimized. Every filter tested removed more winners than losers.

Session / Hour Filter ABANDONED
662 trades analyzed. No hour below 50% WR with meaningful sample size. All sessions profitable (PF 1.12–3.15). No action needed.
Confidence-Based Position Sizing DEFERRED
Correlation r=0.70 confirmed (WR 67.6% → 77.6% by tier). But LOT_STEP 0.01 + MAX_LOT 0.02 = only 2 possible lot sizes. Dynamic sizing lost $129 vs fixed. Deferred until account >$5,000.
Dynamic SL/TP by Session & Volatility ABANDONED
MIN_SL clamping (45.6% of trades) caused by low-ATR markets, not SL miscalibration. ATR filter blocked 341 trades with 68.6% WR. TP contributes 48.6% of winner P&L — essential.
Partial Close (50% at profit target) ABANDONED
Tested 5 trigger levels (25%–75% of TP). Best result: +$18 at 75% (breakeven). Trailing stop already handles profit protection. Net effect zero.
Explicit Regime Detection ABANDONED
All regimes profitable: Trending 72% WR (PF 2.08), Ranging 70% WR (PF 2.49), Normal 74.7%. Central Brain scenarios already provide effective implicit detection.
Multi-Asset Correlation Filter ABANDONED
Conflict trades (BUY gold + DXY rising) have HIGHER WR (76.0%) than aligned (70.7%). Bot overrides macro headwinds with high-conviction calls. Filtering would remove $1,578–$2,174 profit.
Weight Optimization CONFIRMED
96 five-pillar + 19 three-pillar combos tested via walk-forward (12M train / 6M test). Best combo improved test PF by only +0.04 (below +0.10 threshold). Current weights confirmed near-optimal. PF range: 1.70–2.13 (train), 2.13–2.55 (test) — narrow band confirms robustness.
